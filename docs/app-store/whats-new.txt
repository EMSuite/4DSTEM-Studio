Version 5.4.0 is a stability release.

• Grains and phases (no matrix): maps the best phase at every position, with its reliability, for samples of several phases.
• Keep in memory holds the cube at its stored bit depth and is on by default when the cube fits a quarter of the RAM; closing a window frees it at once.
• The origin row reads its own fit: a scattered centre of mass on a spot pattern points to Origin from Bragg Peaks, and a beam stop gets only its own remedy.
• Closing, opening another file or quitting asks before it stops a running analysis; crafted or damaged files are refused instead of stopping the app.
• The agent door reaches more of the app: the EDS room, the view, Settings and the Materials Project.

Results that change: disk detection follows py4DSTEM's default minimum relative intensity (0.5 %), so counts at default settings differ from 5.3.1; EDS absorption on GMS files takes the stage tilt from Stage Alpha and Beta, as exSpy does; viridis, inferno and RdBu are drawn from matplotlib's own tables and tagged sRGB, so map colours shift slightly.
